# World Cup 2026 Prediction Platform

A private prediction platform for the 2026 World Cup, built to make the tournament more fun with friends while demonstrating production-minded software engineering.

The application lets users predict match scores before kickoff, follow focused matches, compare rankings, manage private friend groups, view projected group standings, and track the knockout bracket from the second phase to the final.

## Product Highlights

- Official 2026 World Cup schedule with 104 matches.
- Score predictions locked automatically when each match starts.
- Private friend groups with invite-based access.
- Global position, provisional points, prediction accuracy, and personal statistics.
- Projected group standings and knockout bracket propagation.
- Secure authentication and protected application areas.
- Production deployment with Docker, PostgreSQL, Prisma, and automated tests for core rules.

## Technical Positioning

This project shows how a small, fun idea can be built with the same care expected from professional software: clear domain rules, isolated business logic, secure access, predictable data handling, tested behavior, and a deployment model that can run outside a local development machine.
