## Engineering Skills

Use the following skills when the task materially involves their concern. Read the relevant `SKILL.md` before designing, implementing, or reviewing affected code:

- `clean-code`: Use when creating or refactoring application code, naming, functions, components, or modules where readability and maintainability matter.
- `solid`: Use when introducing or changing responsibilities, dependencies, interfaces, services, or abstractions where SOLID principles help keep the design understandable and testable.
- `luz-dry`: Use when duplicated or near-duplicated logic, validation, queries, UI behavior, or configuration is present or likely to be introduced.
- `secure-by-default`: Use whenever work touches authentication, authorization, sessions/tokens, input validation, server actions, API/route handlers, database access, secrets, configuration, logging, or user data.

Apply only the minimal set relevant to the task. These skills must support simple, readable implementation and must not be used to justify unnecessary abstractions or over-engineering.
